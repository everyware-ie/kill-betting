| 항목 | 내용 |
|------|------|
| 경로 | `/auth/login` |
| 파일 | `app/auth/login/page.js` |
| 상태 | ✅ 구현 완료 |
| 이전 화면 | 없음 (진입점) |
| 다음 화면 | 로그인 성공 → `/dashboard` |

---

## 화면 설명

서비스 진입 시 가장 먼저 보이는 화면.  
아이디와 비밀번호를 입력해서 로그인한다.

---

## 화면 구성 요소

```
┌─────────────────────────────┐
│       KILL CHALLENGE        │  ← 로고 (상단)
│                             │
│  [ ACCESS GRANTED ]         │  ← 배지
│  킬내기 로그인               │  ← 제목
│  전장으로 복귀하기 위해...    │  ← 부제목
│                             │
│  아이디                      │  ← 라벨
│  [ 👤 아이디 입력창 ]        │  ← 입력창
│                             │
│  비밀번호                    │  ← 라벨
│  [ 🔒 비밀번호 입력창 👁 ]   │  ← 입력창 (보기/숨기기 버튼)
│                             │
│  ⚠ 에러 메시지               │  ← 실패 시 표시
│                             │
│  [      로그인      ]        │  ← 로그인 버튼 (황금색)
│  [      회원가입    ]        │  ← 회원가입 버튼 (테두리)
│                             │
│  🔧 Mock 모드 안내           │  ← 개발 환경에서만 표시
└─────────────────────────────┘
```

---

## 동작 방식

### 로그인 버튼 클릭 시
1. 빈 값 체크 → 에러 메시지 표시
2. API 호출: `POST /auth/login`
3. 성공 → `/dashboard` 이동
4. 실패 → 에러 메시지 표시 (예: "비밀번호가 올바르지 않습니다")

### Enter 키
- 아이디 입력창에서 Enter → 로그인 시도

### 비밀번호 👁 버튼
- 클릭 시 비밀번호 보이기/숨기기 토글

---

## 에러 메시지 목록

| 상황 | 메시지 |
|------|--------|
| 아이디 비어있음 | 아이디를 입력해주세요 |
| 비밀번호 비어있음 | 비밀번호를 입력해주세요 |
| 아이디 없음 | 존재하지 않는 아이디입니다 |
| 비밀번호 틀림 | 비밀번호가 올바르지 않습니다 |

---

## 연결된 API

```
POST /auth/login
  요청: { username: string, password: string }
  성공: { user: { id, username } }
  실패: { error: string }
```
