# 08. 최종 결과 리포트

## 기본 정보

| 항목 | 내용 |
|------|------|
| 경로 | `/room/:id/result` |
| 파일 | `app/room/[id]/result/page.js` |
| 상태 | ❌ 미구현 |
| 이전 화면 | 라이브 스코어보드 (경기 종료 후) |
| 다음 화면 | [저장 및 종료] → `/dashboard` |

---

## 화면 설명

킬내기가 완전히 끝난 후 최종 결과를 보여주는 화면.  
우승팀, 팀별 최종 점수, 개인별 통계를 요약해서 보여준다.

## 우승 조건 판단

| 조건 | 우승 팀 |
|------|--------|
| 목표 킬 수 도달 | 먼저 도달한 팀 |
| 시간 초과 | 시간 종료 시점에 가장 높은 점수 팀 |
| 운영자 강제 종료 | 종료 시점에 가장 높은 점수 팀 |

---

## 세션 요약 카드

| 항목 | 표시 내용 |
|------|----------|
| 진행 시간 | 총 경과 시간 (HH:MM:SS) |
| 총 매치 수 | 진행된 판 수 |
| 총 킬 수 | 전체 플레이어 킬 합계 |
| MVP | 개인 킬 1위 플레이어 닉네임 |

---

## 팀별 결과 표시

- 1등부터 순서대로 표시
- 프로그레스바: 최고 점수 팀 기준 100%로 상대 비율 표시
- 점수 구성 표시: `킬 30 + 보너스 +8 - 패널티 0 = 38`

---

## 개인별 통계

| 항목 | 설명 |
|------|------|
| 총 킬 | 전 매치 킬 합계 |
| 데미지 | 전 매치 데미지 합계 |
| 보너스 | 헤드샷/어시스트/치킨 보너스 합계 |
| 패널티 | 팀킬/사망 패널티 합계 |

---

## [저장하고 대시보드로] 버튼

- 결과 저장 API 호출
- 대시보드로 이동
- 방 상태: `LIVE` → `DONE` 변경

---

## 연결된 API

```
GET /rooms/:id
  성공: { room }  ← 방 정보, 팀, 룰

GET /rooms/:id/matches
  성공: { matches }  ← 전체 매치 결과

POST /rooms/:id/end
  킬내기 종료 처리
  성공: { room }  ← status: 'DONE' 으로 변경
```
