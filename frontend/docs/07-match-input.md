# 07. 매치 결과 입력

## 기본 정보

| 항목 | 내용 |
|------|------|
| 경로 | `/room/:id/live` 화면 내 모달 |
| 파일 | `app/room/[id]/live/page.js` 안에 포함 |
| 상태 | ❌ 미구현 |
| 진입 방법 | 라이브 화면에서 [✓ 매치 결과 입력] 버튼 클릭 |
| 닫힘 조건 | [취소] 또는 [결과 반영] 후 → 라이브 화면으로 복귀 |

---

## 화면 설명

배그 게임 한 판이 끝났을 때 결과를 입력하는 화면.  
스크린샷을 올리면 Claude Vision AI가 자동으로 데이터를 읽어온다.  
자동 인식 후 수동으로 수정도 가능하다.

## OCR 동작 방식

### Claude Vision 모드 (API 키 있을 때)
1. 스크린샷 업로드
2. [🤖 Claude Vision으로 분석] 버튼 클릭
3. Claude AI가 이미지에서 자동으로 읽어옴:
   - 각 플레이어별 킬 수
   - 데미지
   - 헤드샷 여부
   - 생존 시간
4. 방에 입력된 **배그 닉네임 기준**으로 결과 매칭
5. 수동 수정 가능

### API 키 없을 때
- 에러 메시지: "API 키가 없습니다. 🔑 API 키 설정 버튼을 눌러 입력해주세요."
- [🔑 API 키 설정] 버튼 클릭 → 키 입력 모달

## 결과 입력 항목

| 항목 | 입력 방식 | OCR 자동입력 |
|------|----------|------------|
| 킬 수 | − + 스테퍼 | ✅ |
| 데미지 | 숫자 입력 | ✅ |
| 헤드샷 | 토글 | ✅ |
| 어시스트 | 토글 | ✅ |
| 팀킬 수 | − + 스테퍼 | ✅ |
| 치킨 여부 | 토글 | ✅ |
| 치킨 팀 | 드롭다운 | ✅ |

---

## 결과 반영 동작

1. [결과 반영] 버튼 클릭
2. API 호출: `POST /rooms/:id/matches`
3. 성공 → 모달 닫힘
4. 라이브 스코어보드 점수 업데이트
5. 매치 히스토리에 기록 추가

---

## 연결된 API

```
POST /rooms/:id/matches
  요청: {
    number: number,       // 매치 번호
    results: [
      {
        nick: string,         // 배그 닉네임
        teamId: string,
        kills: number,
        damage: number,
        headShot: boolean,
        assist: boolean,
        teamKills: number,
        earlyDeath: boolean,
      }
    ],
    chickenTeamId: string | null   // 치킨 달성 팀 ID
  }
  성공: { match }
```
