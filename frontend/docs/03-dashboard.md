# 03. 대시보드

## 기본 정보

| 항목 | 내용 |
|------|------|
| 경로 | `/dashboard` |
| 파일 | `app/dashboard/page.js` |
| 상태 | 🔲 일부 구현 (방 생성 버튼만 있음) |
| 이전 화면 | 로그인 / 회원가입 |
| 다음 화면 | [방 만들기] → `/room/create` |

---

## 화면 설명

로그인 후 가장 먼저 보이는 메인 화면.  
내가 만든 킬내기 방 목록을 보고, 새 방을 만들거나 기존 방에 들어갈 수 있다.

---

## 화면 구성 요소

```
┌─────────────────────────────────────────┐
│  KILL CHALLENGE           [username] [로그아웃]  │  ← 상단 헤더
├─────────────────────────────────────────┤
│  DASHBOARD                              │
│  안녕하세요, username                    │  ← 환영 메시지
│                                         │
│  ┌───────────────────────────────────┐  │
│  │  🎯 킬내기 방 생성                 │  │
│  │  새로운 킬내기 방을 만들고...       │  │  ← 방 생성 CTA
│  │  [    + 방 만들기    ]             │  │
│  └───────────────────────────────────┘  │
│                                         │
│  최근 방 목록                            │  ← 방 목록 (추후 구현)
│  ┌──────────┐ ┌──────────┐             │
│  │ 방 카드   │ │ 방 카드   │             │
│  │ 제목      │ │ 제목      │             │
│  │ LIVE 🔴  │ │ DONE ✓  │             │
│  └──────────┘ └──────────┘             │
└─────────────────────────────────────────┘
```

---

## 동작 방식

### 진입 시
- 비로그인 상태면 `/auth/login` 으로 자동 이동

### [+ 방 만들기] 버튼
- `/room/create` 로 이동

### 방 카드 클릭 (추후 구현)
- 상태가 `LIVE` → `/room/:id/live` 이동
- 상태가 `WAITING` → `/room/:id/setup` 이동
- 상태가 `DONE` → `/room/:id/result` 이동

---

## 방 카드 정보 (추후 구현)

각 카드에 표시할 정보:
- 방 제목
- 게임 모드 (솔로/듀오/스쿼드)
- 상태 배지 (`WAITING` / `LIVE` / `DONE`)
- 생성 날짜
- 참여 팀 수 / 플레이어 수

---

## 상태 배지 색상

| 상태 | 의미 | 색상 |
|------|------|------|
| WAITING | 팀 구성 중 | 노란색 |
| LIVE | 킬내기 진행 중 | 초록색 |
| DONE | 종료 | 회색 |
