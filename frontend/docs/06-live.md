# 06. 라이브 스코어보드

## 기본 정보

| 항목 | 내용 |
|------|------|
| 경로 | `/room/:id/live` |
| 파일 | `app/room/[id]/live/page.js` |
| 상태 | ❌ 미구현 |
| 이전 화면 | 팀 구성 |
| 다음 화면 | [매치 결과 입력] 모달 → 닫으면 다시 이 화면 |
|           | [경기 종료] → `/room/:id/result` |

---

## 화면 설명

킬내기가 진행되는 동안 실시간으로 팀별 점수를 보여주는 화면.  
매치가 끝날 때마다 결과를 입력하면 점수가 누적된다.

---

## 점수 계산 공식

```
팀 총점 = 킬 합계 + 보너스 합계 - 패널티 합계

보너스 계산:
  헤드샷 보너스: 해당 플레이어 킬이 헤드샷이면 +N
  어시스트 보너스: 어시스트 있으면 +N
  치킨 보너스: 해당 매치에서 1등이면 팀에 +N

패널티 계산:
  팀킬 패널티: 팀킬 수 × N
  사망 패널티: 일찍 사망 시 -N
```

---

## 타이머 동작

- 킬내기 시작 시점부터 경과 시간 표시
- 형식: `HH:MM:SS`
- 시간 제한 설정 시 남은 시간도 함께 표시 (빨간색)
- 시간 초과 시 자동 종료 or 알림 (기획 확인 필요)

---

## 운영 메뉴 (방장 전용)

[⚙ 운영 메뉴] 버튼 클릭 시 모달 표시:

| 메뉴 | 기능 |
|------|------|
| 점수 조정 | 특정 팀 점수 수동 가감 (사유 입력 필수) |
| 규칙 변경 | 보너스/패널티 수치 변경 (즉시 적용) |
| 경기 종료 | 킬내기 강제 종료 → 결과 화면으로 |

---

## 승리 조건

- 목표 킬 수에 먼저 도달한 팀이 승리
- 프로그레스바가 100%가 되면 알림 표시
- 시간 제한 있을 경우 시간 초과 시 가장 높은 점수 팀이 승리

---

## 연결된 API

```
GET /rooms/:id
  성공: { room }  ← 방 정보 + 팀 정보 조회

GET /rooms/:id/matches
  성공: { matches: Match[] }  ← 매치 결과 목록

(실시간 업데이트는 폴링 or WebSocket — 백엔드와 협의 필요)
```

---

## 구현 시 주의사항

- 실시간 점수 반영 방식은 백엔드 팀과 협의 필요
  - **폴링**: 5초마다 API 호출 (간단하지만 느림)
  - **WebSocket**: 실시간이지만 구현 복잡
  - MVP는 폴링으로 시작 권장
- 방장이 아닌 참여자는 운영 메뉴 숨김
