# 04. 방 생성 화면

## 기본 정보

| 항목 | 내용 |
|------|------|
| 경로 | `/room/create` |
| 파일 | `app/room/create/page.js` |
| 상태 | ✅ 구현 완료 |
| 이전 화면 | 대시보드 |
| 다음 화면 | 생성 성공 → `/room/:id/setup` (팀 구성) |

---

## 화면 설명

킬내기 방을 만드는 화면.  
방 제목, 게임 모드(솔로/듀오/스쿼드), 보너스/패널티 규칙을 설정한다.  
설정 완료 후 바로 팀 구성 화면으로 넘어간다.

---

## 화면 구성 요소

```
┌─────────────────────────────────────────┐
│  ← 방 생성                  [username]   │  ← 헤더
├─────────────────────────────────────────┤
│                                         │
│  방 정보                                 │  ← 섹션 제목
│  방 제목  [입력창]                        │
│                                         │
│  게임 모드                               │  ← 섹션 제목
│  ┌────────┐ ┌────────┐ ┌────────┐      │
│  │  👤    │ │  👥    │ │ 👨‍👩‍👧‍👦   │      │
│  │ 솔로   │ │ 듀오   │ │스쿼드  │      │  ← 카드 선택
│  │ 1명    │ │ 2명    │ │ 4명   │      │
│  └────────┘ └────────┘ └────────┘      │
│                                         │
│  기본 설정                               │  ← 섹션 제목
│  목표 킬 수    [−][20][+]               │
│  제한 시간     [제한없음 토글] [−][60분][+] │
│                                         │
│  보너스 / 패널티                          │  ← 섹션 제목
│  [토글] 헤드샷 보너스  + [−][2][+]       │
│  [토글] 어시스트 보너스 + [−][1][+]       │
│  [토글] 치킨 보너스    + [−][5][+]       │
│  [토글] 팀킬 패널티    − [−][5][+]       │
│  [토글] 사망 패널티    − [−][1][+]       │
│                                         │
│  ⚠ 에러 메시지                           │
│  [   다음 — 팀 구성 →   ]               │  ← 생성 버튼
└─────────────────────────────────────────┘
```

---

## 게임 모드별 차이

| 모드 | 팀당 최대 인원 | 설명 |
|------|-------------|------|
| 솔로 | 1명 | 1:1 또는 여러 명이 각자 경쟁 |
| 듀오 | 2명 | 2인 1팀 |
| 스쿼드 | 4명 | 4인 1팀 (기본값) |

> 게임 모드 변경 시 팀 구성 화면에서 각 팀의 최대 인원이 자동으로 반영됩니다.

---

## 보너스/패널티 규칙

| 항목 | 기본값 | 설명 |
|------|--------|------|
| 헤드샷 보너스 | +2 켜짐 | 헤드샷 킬 시 추가 점수 |
| 어시스트 보너스 | +1 켜짐 | 어시스트 시 추가 점수 |
| 치킨 보너스 | +5 켜짐 | 1등(치킨) 달성 시 추가 점수 |
| 팀킬 패널티 | -5 켜짐 | 아군을 죽였을 때 감점 |
| 사망 패널티 | -1 꺼짐 | 사망 시 감점 |

> 각 항목은 토글로 ON/OFF, 수치는 − + 버튼으로 변경 가능합니다.

---

## 동작 방식

### [다음 — 팀 구성 →] 버튼 클릭 시
1. 방 제목 빈값 체크
2. API 호출: `POST /rooms`
3. 성공 → `/room/:id/setup` 으로 이동
4. 실패 → 에러 메시지 표시

### ← 뒤로 버튼
- 이전 화면(대시보드)으로 이동

---

## 연결된 API

```
POST /rooms
  요청: {
    title: string,
    rule: {
      gameMode: '솔로' | '듀오' | '스쿼드',
      targetKills: number,        // 목표 킬 수
      timeLimitMin: number,       // 제한 시간 (분)
      noTimeLimit: boolean,       // 시간 제한 없음 여부
      headShotBonusOn: boolean,   headShotBonus: number,
      assistBonusOn: boolean,     assistBonus: number,
      chickenBonusOn: boolean,    chickenBonus: number,
      teamKillPenaltyOn: boolean, teamKillPenalty: number,
      deathPenaltyOn: boolean,    deathPenalty: number,
    }
  }
  성공: { room: { id, title, code, status, rule, teams, ... } }
  실패: { error: string }
```
