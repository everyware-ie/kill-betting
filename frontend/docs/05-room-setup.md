# 05. 팀 구성 화면

## 기본 정보

| 항목 | 내용 |
|------|------|
| 경로 | `/room/:id/setup` |
| 파일 | `app/room/[id]/setup/page.js` |
| 상태 | ✅ 구현 완료 |
| 이전 화면 | 방 생성 |
| 다음 화면 | 시작 → `/room/:id/live` (라이브 스코어보드) |

---

## 화면 설명

킬내기에 참여할 팀과 플레이어를 구성하는 화면.  
배그 인게임 닉네임을 직접 입력해서 팀원을 추가한다.

> ⚠️ **중요**: 여기서 입력하는 닉네임은 배그 인게임 닉네임입니다.  
> 이 서비스의 계정(로그인 아이디)과 관계없습니다.  
> OCR 결과 매칭에 사용되므로 **정확하게** 입력해야 합니다.

## 팀 카드 구성

각 팀 카드는 두 영역으로 나뉩니다.

```
┌─────────────────────────────────┐
│  TEAM ALPHA           MY TEAM   │  ← 내 팀이면 강조 표시
├─────────────────────────────────┤
│  방 참여자                        │  ← 로그인 유저 목록
│  👤 test (나)    ★ OP            │  ← 운영자 배지
│  👤 player2      MEMBER  [OP위임]│
├─────────────────────────────────┤
│  배그 닉네임 (킬내기 참가자)        │  ← 배그 닉네임 목록
│  ● 홍길동                  [✕]   │
│  ● 이순신                  [✕]   │
│                                 │
│  [닉네임 입력...]         [추가]  │
└─────────────────────────────────┘
```

---

## 로그인 유저 팀 배정

### 자동 배정
- 방 입장 시 `members` 빈 자리가 있는 팀 순서대로 자동 배정
- 팀당 최대 인원 = 게임 모드 기준 (솔로1/듀오2/스쿼드4)

### 팀 이동
- 내 팀 아닌 카드에 **[이 팀으로 이동]** 버튼 표시
- 클릭 시 기존 팀에서 나오고 새 팀에 합류

### 운영자(OPERATOR) 규칙
- 팀에 처음 들어온 유저 → 자동으로 OPERATOR
- OPERATOR가 있는 팀에 추가 입장 → MEMBER
- OPERATOR가 팀을 나가면 남은 멤버 중 첫 번째가 자동 OPERATOR 승격
- 현재 OPERATOR는 다른 MEMBER에게 **[OP 위임]** 버튼으로 위임 가능

### OPERATOR 권한 (라이브 화면에서 사용)
- 스크린샷 OCR 업로드
- 매치 결과 수치 수정
- MEMBER는 읽기만 가능

## 배그 닉네임 입력 (킬내기 참가자)

### 닉네임 입력 후 추가
1. 입력창에 배그 닉네임 입력
2. [추가] 버튼 클릭 또는 Enter 키
3. 유효성 검사:
   - 빈 값이면 무시
   - 전체 팀에서 중복되면 에러 표시
   - 팀 정원 초과 시 에러 표시
4. 통과 시 해당 팀 목록에 추가
5. 입력창 초기화

### 닉네임 삭제
- 닉네임 옆 [✕] 버튼 클릭 → 즉시 삭제

### 팀 추가
- [+ 팀 추가] 클릭
- 팀 이름 자동 배정: ALPHA → BRAVO → CHARLIE → DELTA → ECHO → FOXTROT
- 최대 6팀, 초과 시 버튼 숨김

## 킬내기 시작 버튼 조건

| 상태 | 버튼 |
|------|------|
| 빈 팀이 하나라도 있음 | 비활성 (회색) |
| 모든 팀에 1명 이상 | 활성 (황금색) |

---

## 에러 메시지 목록

| 상황 | 메시지 |
|------|--------|
| 닉네임 중복 | '홍길동'은 이미 다른 팀에 등록되어 있습니다 |
| 팀 정원 초과 | TEAM ALPHA은 최대 4명까지 가능합니다 (스쿼드 모드) |
| 빈 팀으로 시작 | TEAM BRAVO에 플레이어를 추가해주세요 |
| 최대 팀 수 초과 | 최대 6팀까지 가능합니다 |

## 룰 수정 모달

헤더의 [⚙ 룰 수정] 버튼 또는 배너의 [수정하기] 클릭 시 모달 표시.

```
┌─────────────────────────────────┐
│  룰 수정                    [✕]  │
│  저장 버튼을 눌러야 반영됩니다     │
├─────────────────────────────────┤
│  게임 모드: [솔로] [듀오] [스쿼드] │
│  목표 킬 수:     [−][20][+]      │
│  제한 시간:  [제한없음] [−][60][+]│
│  [토글] 헤드샷 보너스  + [−][2][+]│
│  ... (보너스/패널티 전체)         │
│                                 │
│  [취소]          [💾 저장하기]   │
└─────────────────────────────────┘
```

**동작 방식:**
- 모달 오픈 시 현재 룰 값으로 초기화
- 수정 내용은 모달 내부 임시 상태에만 저장
- [취소] 클릭 → 변경사항 버림, 모달 닫힘
- [저장하기] 클릭 → API 호출 → 실제 룰 반영 → 모달 닫힘
- 배경 클릭 → 취소와 동일

## 연결된 API

```
GET /rooms/:id
PUT /rooms/:id/teams   ← 팀 구성 저장
PUT /rooms/:id/rule    ← 룰 수정 저장 (모달 [저장하기] 클릭 시)
POST /rooms/:id/teams  ← 팀 추가
POST /rooms/:id/start  ← 킬내기 시작
```
