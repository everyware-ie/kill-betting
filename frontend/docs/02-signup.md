# 02. 회원가입 화면

## 기본 정보

| 항목 | 내용 |
|------|------|
| 경로 | `/auth/signup` |
| 파일 | `app/auth/signup/page.js` |
| 상태 | ✅ 구현 완료 |
| 이전 화면 | 로그인 화면 |
| 다음 화면 | 가입 성공 → `/dashboard` |

---

## 화면 설명

새 계정을 만드는 화면.  
아이디와 비밀번호만 입력하면 된다. **닉네임은 없다.**

> ⚠️ **중요**: 닉네임 필드가 없는 것은 의도적인 설계입니다.  
> 배그 닉네임은 계정에 저장하지 않고, 킬내기 방 팀 구성 시 직접 입력합니다.  
> (다른 사람 닉네임 선점 문제 방지)

---

## 화면 구성 요소

```
┌─────────────────────────────┐
│  👤 회원가입                 │  ← 제목
│  킬내기 방 운영을 위한 계정...  │  ← 부제목
│                             │
│  아이디          영문·숫자 2~20자  │  ← 라벨 + 힌트
│  [ 아이디 입력창 ] [중복확인]  │  ← 입력창 + 버튼
│  ✓ 사용 가능한 아이디입니다   │  ← 중복확인 결과
│                             │
│  비밀번호        최소 4자리 이상  │  ← 라벨 + 힌트
│  [ 비밀번호 입력창 👁 ]       │  ← 입력창 (보기/숨기기)
│                             │
│  ☐ 약관 동의 체크박스         │  ← 체크박스
│                             │
│  ⚠ 에러 메시지               │  ← 실패 시 표시
│                             │
│  [    회원가입 완료 ›   ]     │  ← 가입 버튼
│  이미 계정이 있으신가요? 로그인  │  ← 링크
└─────────────────────────────┘
```

---

## 동작 방식

### 아이디 중복 확인
1. 아이디 입력 후 [중복확인] 버튼 클릭
2. API 호출: `GET /auth/check-username?username=xxx`
3. 사용 가능 → 초록색 "✓ 사용 가능한 아이디입니다"
4. 중복 → 빨간색 "⚠ 이미 사용 중인 아이디입니다"
5. 아이디를 다시 수정하면 확인 결과 초기화

### 회원가입 완료 버튼 클릭 시
1. 중복확인 완료 여부 체크
2. 비밀번호 4자 이상 체크
3. 약관 동의 체크
4. API 호출: `POST /auth/signup`
5. 성공 → 자동 로그인 상태로 `/dashboard` 이동
6. 실패 → 에러 메시지 표시

---

## 유효성 검사 규칙

| 항목 | 규칙 |
|------|------|
| 아이디 | 영문+숫자+언더스코어(_)만, 2~20자, 중복 불가 |
| 비밀번호 | 최소 4자 이상 |
| 약관 동의 | 반드시 체크 필요 |
| 닉네임 | **없음** |

---

## 에러 메시지 목록

| 상황 | 메시지 |
|------|--------|
| 중복확인 미완료 | 아이디 중복 확인을 완료해주세요 |
| 비밀번호 짧음 | 비밀번호는 최소 4자 이상이어야 합니다 |
| 약관 미동의 | 이용 약관에 동의해주세요 |
| 아이디 형식 오류 | 아이디는 영문·숫자·언더스코어 2~20자만 가능합니다 |
| 아이디 중복 | 이미 사용 중인 아이디입니다 |

---

## 연결된 API

```
GET /auth/check-username?username={username}
  성공: { ok: true }
  실패: { error: '이미 사용 중인 아이디입니다' }

POST /auth/signup
  요청: { username: string, password: string }
       ※ nickname 없음 (의도적)
  성공: { user: { id, username } }
  실패: { error: string }
```
