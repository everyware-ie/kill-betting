## 화면 설명

내 계정 정보를 확인하고 수정하는 화면.  
아이디 변경, 비밀번호 변경, 킬내기 전적 확인.

> ⚠️ **중요**: 닉네임 변경 없음.  
> 배그 닉네임은 계정과 무관하므로 마이페이지에서 관리하지 않습니다.

## 아이디 변경 동작

1. 새 아이디 입력
2. [중복확인] 버튼 클릭
3. API 호출: `GET /auth/check-username?username=xxx`
4. 사용 가능 확인 후 [아이디 변경] 버튼 활성화
5. [아이디 변경] 클릭 → `PATCH /user/username`
6. 성공 → 화면에 새 아이디 반영

---

## 비밀번호 변경 동작

1. 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인 입력
2. 새 비밀번호 ≠ 새 비밀번호 확인이면 에러
3. [비밀번호 변경] 클릭 → `PATCH /user/password`
4. 성공 → 입력창 초기화

---

## 전적 표시

- 로그인 유저의 킬내기 참여 전적
- 방 종료 시 자동으로 승/패 기록됨 (`UserAPI.recordGame()`)

> 현재 전적은 방 단위 승/패 기준입니다.  
> (개인 킬 수 기반 통계는 추후 기획 확정 필요)

## 연결된 API

```
GET /auth/check-username?username={username}
  아이디 중복 확인

PATCH /user/username
  요청: { username: string }
  성공: { username }

PATCH /user/password
  요청: { currentPassword: string, newPassword: string }
  성공: { message }
  실패: { error: '현재 비밀번호가 올바르지 않습니다' }

GET /user/stats
  성공: { total_games, wins, losses, win_rate }
```
