## 서비스 한 줄 설명

배틀그라운드 커스텀 게임의 **킬내기**를 자동으로 관리하는 웹 서비스.  
스크린샷을 올리면 OCR로 결과를 자동 인식하고, 팀별 킬 점수를 실시간 집계한다.

---

## 사용자 흐름 (전체)

```
[로그인 / 회원가입]
        ↓
  [대시보드]  ← 내 방 목록, 방 만들기 버튼
        ↓
  [방 생성]   ← 제목, 게임 모드, 룰 설정
        ↓
  [팀 구성]   ← 배그 닉네임 직접 입력
        ↓
[라이브 스코어보드]  ← 실시간 킬 현황
        ↓
[매치 결과 입력]  ← 스크린샷 업로드 → OCR
        ↓
[최종 결과 리포트]  ← 우승팀, 개인 통계
```

## 꼭 알아야 할 핵심 개념 2가지

### 1. 방 참여자 ≠ 킬내기 참가자

```
방 참여자 (Participant)
  - 로그인해서 방에 들어온 사람
  - 결과 입력, 방 관리 담당
  - ID(계정)로 식별

킬내기 참가자 (Player)
  - 실제 배그에서 뛰는 사람
  - 배그 닉네임 문자열만 존재
  - 계정 연동 없음 → 팀 구성 화면에서 직접 입력
```

**왜 분리했나?**  
누군가가 다른 사람의 배그 닉네임으로 계정을 만들어 선점하는 문제를 방지하기 위함.

---

### 2. 회원 정보에 닉네임 없음

- 로그인은 **ID + 비밀번호**만 사용
- 배그 닉네임은 계정에 저장하지 않음
- 킬내기할 때마다 팀 구성 화면에서 직접 입력

## API 전환 방법 (개발 → 실제 서비스)

현재는 **Mock 모드** (가짜 데이터)로 동작합니다.  
백엔드 API 완성 후 아래 2줄만 바꾸면 됩니다.

```js
// lib/api.js 상단
const USE_MOCK = false;   // ← true → false
const API_BASE_URL = 'https://api.killchallenge.com';  // ← 실제 주소
```
