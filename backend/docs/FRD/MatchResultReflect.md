## 1. Overview

- 사용자가 검토(확정)한 PUBG: Battlegrounds 매치의 **팀 결과**를 킬내기 세션에 반영한다.
- 팀 단위 성과(킬 수, 순위 등)를 기반으로 세션 점수 및 랭킹을 계산한다.

---

## 2. Roles & Permissions

### 2.1 역할 정의

- **Uploader (업로드 담당자)**
  - 팀 매치 결과 업로드 가능
- **Team Member (일반 팀원)**
  - 업로드 불가 (조회만 가능)


### 2.2 권한 정책

- 업로드는 Uploader 역할을 가진 사용자만 가능
- 한 팀당 업로드 담당자는 1명

---

## 3. User Flow

1. 사용자가 매치 결과(팀 기준)를 업로드
2. 결과 검토 및 수정
3. “검토 완료(confirmed)” 상태로 변경
4. 해당 매치가 연결된 킬내기 세션 조회
5. 팀 결과를 세션에 반영
6. 팀 랭킹 및 점수 업데이트

---

## 4. Functional Requirements

### 4.1 조건

- 매치 결과 상태가 “confirmed”여야 한다
- 해당 매치가 특정 킬내기 세션에 연결되어 있어야 한다
- 팀 단위 결과 데이터가 존재해야 한다
- 업로드 담당인 사용자가 업로드해야 한다

---

### 4.2 데이터

- 팀 ID
- 팀 총 킬 수
- 팀 순위
- 팀 생존 시간
- 개인별 딜량, 킬수
- 치킨 여부

### ✔️ 점수 계산 예시

- 점수 = (팀 킬 수 × k) + 순위 보너스

---

### 4.3 결과

- 팀 점수 업데이트
- 세션 내 팀 랭킹 재정렬
- 해당 매치가 “반영 완료” 상태로 표시됨

---

## 5. Acceptance Criteria

- [ ]  검토 완료된 매치만 세션에 반영된다
- [ ]  팀 단위 결과가 세션 점수에 반영된다
- [ ]  동일 매치는 한 세션에 1회만 반영된다
- [ ]  반영 후 팀 랭킹이 즉시 업데이트된다
- [ ]  반영 결과가 UI에 반영된다
- [ ]  반영 실패 시 에러 메시지가 표시된다
- [ ]  업로드 담당자만 매치 결과를 업로드할 수 있다
- [ ]  권한 없는 사용자가 업로드 시도 시 요청이 거부된다
- [ ]  권한 오류 시 적절한 에러 메시지가 반환된다
- [ ]  팀에 속하지 않은 사용자는 업로드할 수 없다

---

## 6. Edge Cases

- 팀 구성원이 일부만 세션에 참여한 경우
- 매치에는 팀이 있지만 세션에는 개인만 존재하는 경우
- 세션 종료 이후 반영 시도
- 검토 취소 시 (rollback 필요 여부)
- 팀 ID 불일치 / 매핑 실패
- 업로드 담당자가 아닌 경우

---

## 7. Non-functional Requirements

- 데이터 정합성 보장 (트랜잭션 처리)
- 중복 반영 방지 (idempotency key: matchId + teamId)
- 반영 처리 시간 1초 이내

---

## 8. Out of Scope

- 팀 구성 변경
- 점수 계산 방식 변경 UI
- 매치 데이터 자동 분석 (OCR 등)
