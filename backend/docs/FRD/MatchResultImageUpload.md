## 1. Overview

- 사용자는 PUBG: Battlegrounds 매치 종료 후 팀 결과 이미지를 업로드할 수 있어야 한다.
- 업로드된 이미지는 팀 기록 저장 및 공유에 사용된다.

---

## 3. User Flow

1. 사용자가 매치 종료
2. 결과 화면 확인
3. 앱 실행 후 업로드 기능 진입
4. 이미지 선택 (갤러리 or 캡처)
5. 업로드 버튼 클릭
6. 업로드 성공/실패 결과 확인

---

## 4. Functional Requirements

### 4.1 입력

- 사용자는 이미지 파일을 업로드할 수 있어야 한다
- 지원 포맷: JPG, PNG

### 4.2 동작

- 업로드 버튼 클릭 시 서버로 이미지 전송
- API: `POST /api/sessions/{sessionId}/matches`
  - `sessionId`: 이미지가 속할 세션 ID (path variable)
  - `image`: 업로드할 이미지 파일 (multipart/form-data)
  - 서버가 match를 생성하고 `matchId`를 반환

### 4.3 결과

- 성공 시:
  - 업로드 완료 메시지 표시
  - 해당 매치 기록에 이미지 연결
- 실패 시:
  - 에러 메시지 표시

---

## 5. Acceptance Criteria

- [ ]  사용자는 매치 종료 후 이미지를 업로드할 수 있다
- [ ]  유효한 이미지 파일만 업로드 가능하다
- [ ]  업로드 성공 시 성공 메시지가 표시된다
- [ ]  업로드 실패 시 원인을 포함한 에러 메시지가 표시된다
- [ ]  업로드된 이미지는 해당 매치 데이터에 연결된다

---

## 6. Edge Cases

- 이미지 파일이 아닌 경우 (ex. PDF)
- 파일 크기 초과 (예: 10MB 이상)
- 네트워크 끊김
- 동일 이미지 중복 업로드
- 업로드 중 앱 종료

## 7. Non-functional Requirements

- 업로드 처리 시간: 3초 이내
- 이미지 저장 시 압축 또는 리사이징 적용
- HTTPS 통신 필수

---

## 8. Out of Scope

- 이미지 편집 기능
- 자동 결과 인식 (OCR)
- 영상 업로드
